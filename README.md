# Student Performance Analysis

## Project Overview

This project was completed as part of my Data Science & Data Analytics internship at Cognevance Technologies.

The project analyzes student academic performance using a sample dataset of 500 students.

## Objectives

* Analyze student attendance and exam marks.
* Identify student performance trends.
* Compare pass and fail percentages.
* Explore the relationship between attendance and overall scores.

## Tools Used

* Microsoft Excel
* Data Analysis
* Data Visualization

## Dataset

The project uses a synthetic sample dataset containing 500 student records.

## Project Files

* Excel workbook with analysis and charts
* Student dataset (CSV)
* Project report (DOCX)

## Key Findings

* Average attendance: 67.44%
* Average exam marks: 65.64
* Pass percentage: 94.8%
* Attendance and overall score show a positive correlation (0.716).

## Conclusion

This project helped me practice data cleaning, exploratory data analysis, visualization, and insight generation using Microsoft Excel.
